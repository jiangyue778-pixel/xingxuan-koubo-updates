# 星选提取｜批量下载视频与转写文案

星选提取是浏览器扩展，支持抖音、小红书和快手的单条及批量视频下载、字幕提取和浏览器内中文转写。单条文案可复制或导出 TXT，批量文案可导出 CSV 或 Excel。请只处理有权访问和使用的作品。

## 安装与更新

- 从 [Chrome 网上应用店的星选提取](https://chromewebstore.google.com/detail/piagegkacadbjadneljndcbjmknpombg) 获取当前可用版本。商店安装的扩展由 Chrome 更新。
- 当前 Chrome 商店正式版为 0.10.106，实际可用版本以商店为准。
- Chrome 扩展在浏览器内运行，无需安装 Windows EXE、启动本地服务或另装语音模型。各内容平台的登录和访问要求仍然适用。

这个仓库保留历史 Windows 更新包和 Firefox 中文语音模型，供对应旧版本使用。

## 支持

支持反馈功能的版本可在插件内打开「反馈与建议」，免登录提交问题、使用体验或功能建议。
